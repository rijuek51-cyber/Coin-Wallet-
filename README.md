# Coin Wallet Android UI prototype

Native Kotlin / Jetpack Compose Android project based on the screenshots supplied by the user.

## Features in this prototype
- Sign-in / create-account visual flow (demo only)
- Portfolio dashboard and sample market list
- Asset search and All / Major / TRON / Meme filters
- Asset detail page and price-history placeholder
- Receive, Send and Swap screens
- Activity list, address book, price-alert settings
- Add-token form and settings/security screen
- Dark navy + cyan visual design

## IMPORTANT
This is a **non-custodial wallet UI prototype only**, not a working wallet. Prices, holdings and history are sample data. It does not create/import keys, derive addresses, connect to a blockchain, sign transactions, broadcast transfers, or execute swaps. Login fields are not transmitted or stored. Do not use it for real funds or enter a seed phrase/private key. A production release needs audited key management, secure signing, chain RPC integration, transaction simulation, fee estimation, verified market data, backup/recovery, and independent security review.

## Build
GitHub Actions workflow is included at `.github/workflows/build-apk.yml`.
1. Create an empty GitHub repository.
2. From this directory, run:
   `git init && git add . && git commit -m "Coin Wallet Android prototype"`
3. Add your GitHub remote and push the `main` branch.
4. In GitHub, open **Actions** → **Build Coin Wallet APK** → **Run workflow**.
5. Download the `CoinWallet-debug-apk` artifact and install `app-debug.apk` on Android.

Package ID: `com.coinwallet.app`
