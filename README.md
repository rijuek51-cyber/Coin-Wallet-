# Coin Wallet Android

A native Android cryptocurrency wallet UI prototype.

## Technology
- Kotlin
- Jetpack Compose
- Android Gradle
- Package ID: com.coinwallet.app

## Features
- Sign-in and account creation demo
- Portfolio dashboard
- Cryptocurrency asset list
- Asset search and filters
- Asset detail screens
- Receive, Send and Swap UI
- Transaction activity
- Address book
- Price alerts
- Settings and security screens

## Security Notice
This is a UI prototype, not a production cryptocurrency wallet.

It does not currently create or import wallet keys, sign blockchain transactions, or transfer cryptocurrency.

Never enter real seed phrases or private keys.
